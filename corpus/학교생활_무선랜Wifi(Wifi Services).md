# Wifi Services (교내 무선랜 접속)

> ⚠️ 사이트 메뉴명이 뒤바뀌어 있습니다. 왼쪽 메뉴 "Wifi Services"의 실제 URL은 `InternetUtilization.do`이고, "Internet Utilization" 메뉴가 IP/서버 계정 페이지입니다.

##### Wireless LAN (WiFi) Connection Procedure

**1. University Member (학내 구성원)**

- Select SSID **"SKKU"** → enter Kingo ID / Password and connect.
- ※ For non-degree students: enter **Student Number / Date of Birth** (e.g. 990225 for 25 Feb 1999).
- ※ For Android OS, set up manual options (see manuals below).

**2. Visitor (방문자)**

- Select SSID **"SKKU_GUEST"** → enter a mobile number and the password received by SMS.
- ※ A guest account is available for **1 day**.
