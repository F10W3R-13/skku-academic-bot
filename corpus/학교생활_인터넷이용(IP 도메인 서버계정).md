# Internet Utilization (IP·도메인·서버 계정)

> ⚠️ 메뉴명이 뒤바뀐 페이지입니다. 왼쪽 메뉴 "Internet Utilization"의 실제 URL은 `WifiServices.do`이며, 내용은 IP/도메인/서버 계정 신청입니다.

##### IP Address Application and Returns

- Each computer or online host is assigned an IP address. SKKU members can only access the network from a designated IP address.
- To return an IP address, contact the Information Communication Team: 031-299-6214.

##### Domain Name Application and Returns

- The IP address received from SKKU can be assigned a domain name. SKKU domains are skku.edu, skku.ac.kr, etc.
- To return a domain name: 031-299-6214.

##### Application for HOST Open

- The campus network is protected by a firewall, IPS, etc. Certain services are blocked; to open the HOST for research or other specific purposes, a request must be made.
- Security risks from an open HOST are the user's personal responsibility. Contact the Information Communications Team to request deletion once finished.

##### Server Account Application

When labs, clubs, or societies consisting of **two or more people** wish to create a website, the Office of Information and Communications provides a server account.

**Server Environment**

- OS: UNIX (SUN Solaris) / Language: PHP / DB: MySQL / Web Server: Apache
- Others: telnet, ftp open port / Capacity: 200M

**How to Apply** — Sign in to the Office of Information and Communications website → Select Application Form: Apply for Server(DB) Account → Create / Change / Delete Account

**Requirements Before Applying**

- Create Server Account ID (4~12 character combination of letters and numbers)
- Decide whether to use a DB account (generally used for bulletin boards)
- Receive designation of administrator
- Get approval from a supervisor or account server staff

**Approval Notification** — sent to your Kingo e-mail address before 12:00 PM on the next working day.

**Account Server Management Rules**

- Account servers cannot be used for any purpose other than website services.
- Installation of software that could influence the whole service may be restricted.
- When used as a file server (backing up files, etc.), files may be deleted without prior notice.
- All services and management tasks except provision of an account are the administrator's responsibility.
- Take special care managing passwords; if lost, contact the Office of Information and Communications.

Inquiries: 031-290-5221
