# Mobile App Use — KINGO-M (모바일 앱)

Portal App services refer to services provided through the SKKU mobile application (**KINGO-M**).

##### How to install the Mobile Portal App (Android)

1. Go to the Play Store on your Android phone.
2. Type "Sungkyunkwan University" in the search bar and select install.
3. After installation, start **KINGO-M** from the menu.
4. If using a QR code, go to "Sungkyunkwan University Kingo-M" in the Play Store.

##### 관련 메모 (다른 페이지에서 확인된 KINGO-M 기능)

- **모바일 학생증** — 실물 학생증 발급 이후에만 활성화됨 (→ `학생증(다기능학생증).md`)
- **증명서 발급** — KingoM App > About SKKU > Certificate Issue (→ `증명서발급(Certificate Issuing).md`)
- **출결 체크** — 강의실 출결단말기에 NFC 신분증 또는 QR코드 태깅
