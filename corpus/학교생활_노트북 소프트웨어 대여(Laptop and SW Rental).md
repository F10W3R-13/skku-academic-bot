# Laptop and Software Rental Services (노트북·소프트웨어 대여)

## 1. Laptop Rental (노트북 대여)

### Loan Conditions

- **Eligibility**: students (including graduate students) registered for the current semester
- **Devices**: laptop computers equipped with a wireless LAN card
- **Rental Period**: limited to **150 hours per semester** per person; devices must be used only for education/research/academic purposes

| Category | Time | Remarks |
|---|---|---|
| Rentals | 9:30 AM ~ 3:00 PM | Laptops may not be checked out during nighttime, holidays and weekends; **devices may not be taken off campus**. If using overnight, they must be returned by 10 AM the next day. |
| Return — during semester | 10:00 ~ 20:00 (both campuses) | |
| Return — during breaks | 10:00 ~ 17:00 | |

* Rental/return services are closed during lunch (12:00 ~ 13:00).

- **Fee**: free. However, if a loaned device is lost or damaged, the borrower must pay the full restoration cost.

### Application Method

Sign in to GLS → make a reservation through the **Information Square IT Service** → present ID (both Student ID Card and Resident Registration Card) at the Information Communications Division → fill out a loan service agreement form. Check the device for problems yourself when borrowing — you are responsible for consequences of negligence.

### Reservation Cancellation

Cancel through the website before borrowing. Failing to do so counts as a violation and is treated as a delay in return.

### Rental Locations

- Humanities and Social Sciences Campus: PC Center, 4F, Dasan Hall of Economics (02-760-1258)
- Natural Sciences Campus: PC Center, 4F, Engineering Bldg. 2 (031-299-6215)

### Delay in Return — Penalties

| Number of Delayed Returns | Penalty |
|---|---|
| 1 | Rental suspended for 1 month |
| 2 | Rental suspended for 6 months |
| 3 and over | Permanent suspension |
| Failure to return or compensate | Claim for damages and disciplinary measures until returned or compensated; legal measures if not complied with |

### Responsibility for Data

The Information Communications Division has no obligation to preserve any personal data left on a returned device; the borrower is responsible for such data loss.

### Antivirus Software (V3)

On-campus security software is distributed as **'PC Integrated Security'**, which includes:

- Antivirus software — PC protection from malware
- Patch management — updates/patches for OS and major software
- Personal information management — search and encrypt/delete personal information on PC
- Vulnerability check (My PC Guard) — measure and improve PC security levels

**Download location**

- Portal (https://eportal.skku.edu) → Board → Info. Security → [Bulletin] 'Guide for integrated security program (including antivirus S/W) installation…'
- Security Portal (https://security.skku.edu) → Library → Security S/W → [Bulletin] 'PC integrated security program'

⚠️ If you install the antivirus alone without the PC integrated security program, **external internet connection may be blocked on the campus network**.

### Software Rental Type

- Install and authenticate yourself after renting a CD: **Hangul**
- Install yourself and request authentication by call after renting a CD: **MS Windows, Office**
- Installed remotely by the PC center upon request: **SPSS**
- Install and authenticate yourself via webpage: **V3, SAS, MATLAB, Adobe, STATA, ALTOOLS**

### Software Rental Principles

SW can only be installed on campus; the rental period is **1 night and 2 days**.

| Type | Time |
|---|---|
| Rent | 09:00 ~ 17:00 |
| Return | 09:00 ~ 17:30 (by 10:00 the next weekday) |

1. Rental/return not available 12:00~13:00 (lunch).
2. Rent Mon–Thu → return by 10:00 next day; rent Friday → return by 10:00 the following Monday.
3. No rental/return on holidays, Saturdays and Sundays.
4. An external CD drive can be rented if you have no CD-ROM device.
