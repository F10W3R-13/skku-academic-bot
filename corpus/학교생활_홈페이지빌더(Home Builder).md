# Home Builder — SKKU Web Builder (SWB)

SKKU Web Builder (SWB) is the University's website creation tool that makes it easy to create websites from pre-built templates.

SWB can be used **only** for university administrative organizations, colleges and schools, and graduate schools. It is **not available for personal blogs or commercial websites**.

##### How to use

1. Access SKKU Web Builder: http://swb.skku.edu
2. Sign in with your SKKU ID
3. Request to open a website
4. Get approval from the Information & Communication Team and start building
