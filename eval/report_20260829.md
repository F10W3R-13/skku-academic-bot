## 핵심 발견

1. **검색 경로의 완전 결정성 입증 (질의 캐시 효과)** — 4차와 5차에서 CONTEXT_MISS 문항 목록,
   컨텍스트 팩트 포함 214/225, 컨텍스트 통계가 전부 동일하다. 3차 리포트가 지적했던 "경계 변동대
   (실행마다 8~12문항 통과/실패 오감)"의 검색 측이 사라졌다. 남은 3문항 GENERATION_MISS 흔들림은
   답변 생성 모델의 샘플링(seed 미준수)에서 오며, 검색과 분리됐다.
2. **BM25 어휘 보너스: 회귀 없음** — 자동 PASS 112 vs 114, 팩트 포함 95% 유지 (변동 폭 안).
   대신 제거된 실패 클래스: 표 위주 청크가 질의와 연결 안 되던 문제(ATM 위치 표). 단위 테스트 4개로
   방어(희귀 토큰 승격 / 흔한 토큰 무력 / 영어 표 매칭 / 기능어 필터).
3. **반복 질문 2.5배 빨라짐** — 11.4s → 4.5s (질문당 split/expand LLM 호출 2회 절약).
4. 유의: 4차는 캐시가 비어 있던 실행(변동 재현), 5차는 같은 질문에 같은 검색 경로를 탄 실행.
   이후 eval은 5차처럼 결정적으로 재현된다 — 프롬프트를 바꾸면 캐시 서명이 바뀌어 자동 재수집.
